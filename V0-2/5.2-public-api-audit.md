## Notes for the reviewer

- `AgentStream.partialHistory` is covered by `AgentStreamCancelHistoryTests` and `V02CrossFeatureTests`. Neither asserts it after a cancelled `resume(from:)`, which builds a recorder in `AgentStream.resume` but is not asserted.
- `AgentStream.send` and `AgentStream.init` are public and undocumented. They predate v0.2, but `send` changed body. Not changed per task rules.
- `PartialTurnRecorder.init()` is package and undocumented. Not changed.
- `sanitizedTerminalHistory` is package, its behavior changed in item 2, and it has no doc comment.
- FoundationModels and MLX changes: `public` moved to `public extension`. Access is unchanged; the explicit keyword is gone. The `#if` blocks are not compiled on Linux, so their docs and tests were checked by reading only.
- No test-only hooks were found among the public symbols.
